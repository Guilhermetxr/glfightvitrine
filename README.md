# Site de apresentação GL Fight
Site independente da atleta e proprietária da GL Fight. Identidade preta e roxa e foto fornecida pela cliente.

## Abrir
Execute `npm run dev` nesta pasta e acesse `http://localhost:5174/`. O servidor expõe somente esta pasta. Para a navegação local à loja, mantenha o servidor dela na porta 5173.

## Conteúdo
Edite `js/atleta.js` para informar nome, Instagram, biografia e conquistas confirmadas. Enquanto não forem informados, a página usa uma apresentação geral baseada nas informações fornecidas, sem inventar títulos específicos, anos ou quantidades de medalhas.

## Publicação
O site é estático. Publique apenas esta pasta. Antes, substitua em index.html os links `../GLfight/index.html` pelo endereço público da loja. Nenhuma publicação foi realizada.
